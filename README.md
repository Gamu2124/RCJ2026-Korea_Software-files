This repository contains software developed for our RoboCup Junior Soccer Open 2026 robot.

### Overview

This repository contains firmware for several subsystems used in our RoboCup Junior Soccer Open 2026 robot.

Included projects:

- **Ball Sensor** – Firmware for the ball detection board.
- **Line Sensor** – Firmware for the line detection board.
- **UI Board** – Firmware for the user interface board.
- **ESC Control** – Brushless motor (dribbler) ESC control program.

Each project is independent and is intended for its corresponding hardware.

### Development Environment

- Arduino IDE
- C++
- Teensy 4.1

### Repository Structure

```
RCJ2026-Korea_Software-files
├── BallSensor/
├── LineSensor/
├── UI/
└── ESC/
```

### Notes

The software was developed for our competition robot. Hardware configuration and pin assignments may need to be modified for other systems.
